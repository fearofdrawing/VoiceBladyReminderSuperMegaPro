# Voice Reminder v0.2 — test build
Android 10+ prototype. Dark interface, English/Latvian speech input selection, basic relative and clock time parsing, guided audio recording with amplitude-based silence detection, TTS confirmation, back buttons, reminder history and snooze options. Speech recognition may require network support. Test alarms and permissions on each device; do not rely on this prototype for critical reminders.

## Upload to GitHub
Upload the **contents of this folder** at the repository root (not nested inside another VoiceReminder folder). Then Actions → Build Voice Reminder APK → Run workflow.

This source has not been compiled or device-tested in the authoring environment.
